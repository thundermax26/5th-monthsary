LEILA'S LITTLE LOVE SCRAPBOOK
==============================

WHAT'S INSIDE
- index.html: the complete website
- photos/: put your chosen photos here if you want to use file paths
- music/: put your music file here, named our-song.mp3

QUICK CUSTOMIZATION
1. Open index.html in a text editor (Notepad or VS Code).
2. Search for the sample letter and replace it with your own words.
3. Edit the five month card descriptions and note messages if you want.
4. The photo upload buttons preview photos only in the current browser session.
   For Leila to see your photos on the published website, add image files to the
   photos folder and edit the HTML image placeholders to use those files.
   Example: <img src="photos/our-photo.jpg" alt="Our photo">
   Then remove the inline display:none style from that image, or adjust the CSS.
5. Add your own MP3 file at music/our-song.mp3. Use music you have permission to share.
   The music starts only after the visitor presses the play button.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in at https://github.com
2. Click the + button (top right) -> New repository.
3. Name it leila-five-months (or another name), choose Public, then Create repository.
4. On the new repository page, choose Add file -> Upload files.
5. Upload index.html and the photos and music folders (including your files).
   You can also unzip this package on your computer and drag the contents into GitHub.
6. Click Commit changes.
7. Open Settings -> Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Select branch main and folder /(root), then Save.
10. Wait a minute or two. Your site will appear at:
    https://YOUR-GITHUB-USERNAME.github.io/leila-five-months/

IMPORTANT
- Keep index.html at the repository root, not inside another folder.
- Test the link on your phone before sending it to Leila.
- If the site doesn't appear immediately, wait a little and refresh the Pages settings.
- GitHub Pages is static hosting. This site needs no database or server.
